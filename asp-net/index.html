Nous intervenons sur les applications web .NET qui doivent évoluer, améliorer leurs performances, exposer des services ou sécuriser leur maintien en production.

Situations rencontrées

  • Application ASP.NET historique à remettre à niveau
  • Fonctions métier à exposer via API ou webservices
  • Correctifs et évolutions à industrialiser
02

Interventions possibles

  • Reprise et analyse du code existant
  • Développement back-end, interfaces et services
  • Intégration SQL Server, Oracle ou autres sources

03

Trajectoires d’évolution

  • Comparer mise à niveau, refactoring et réécriture ciblée
  • Sécuriser les parcours critiques par des tests de non-régression

Données, interfaces et exploitation

La reprise couvre aussi les données, les interfaces, les traitements planifiés, les environnements, les règles métier et les procédures de mise en production. C’est ce périmètre complet qui permet de choisir entre maintenance, montée de version, refactoring et migration.
