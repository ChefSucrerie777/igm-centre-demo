# Démonstration du site IGM

[Voir la démonstration](https://chefsucrerie777.github.io/igm-centre-demo/)

Ce dépôt contient uniquement les fichiers statiques destinés à la consultation publique : pages HTML, styles, images et logos. Les sources de développement, documents de travail et historique du projet ne sont pas inclus.

Cette démonstration ne remplace pas le site officiel [igmcentre.fr](https://www.igmcentre.fr). Les pages portent une consigne de non-indexation ; cela ne constitue pas une restriction d’accès.

Les marques, logos et contenus restent la propriété de leurs titulaires respectifs.
